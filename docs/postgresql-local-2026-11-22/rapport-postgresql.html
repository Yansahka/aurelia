Aurelia connecté à PostgreSQL

Validation locale du 22 novembre 2026.

Configuration active

PostgreSQL 18.7 sur localhost:5432, base aurelia_db. Les migrations 001 et 002 sont appliquées. L’API utilise un rôle SQL dédié sans SUPERUSER ni BYPASSRLS.

npm start, npm run dev et npm run dev:local démarrent désormais l’API sur PostgreSQL natif. Aucun repli automatique vers PGlite.

Les secrets de l’API sont dans .env ; ceux du propriétaire dans .env.migrations. Ces fichiers sont exclus de Git. Les données historiques PGlite restent préservées dans .local/, sans import automatique.

Régression

npm test : 21 tests réussis, aucun échec au dernier passage. Ces tests restent isolés via PGlite pour les contrôles rapides. Le test historique d’arrêt brutal PGlite a dépassé son délai de 30 secondes lors de deux passages initiaux ; il a ensuite réussi seul puis dans la suite complète. Cette variabilité du moteur embarqué n’affecte pas l’API native.

La commande npm run db:setup-local a aussi été relancée : migrations et rôle existants sont réutilisés sans recréer de compte.
